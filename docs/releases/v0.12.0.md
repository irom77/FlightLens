# FlightLens 0.12.0

Optional AI summaries are available for Inspector and two- or three-backup
Compare views. This minor release adds customized, sanitized filename suggestions
when saving AI summaries as Markdown, and automatic persistence for the last performed
AI summary in the frontend's Zustand store, allowing seamless navigation back and
forth between active backups or compared backups without losing summary results.

Results are plain text with model attribution and a disclaimer. They can be
copied or saved as Markdown with backup hashes, selected profiles and comparison
baseline provenance. Keys use the OS credential store or explicitly selected
session-only storage. Summary caches exist only in memory.

## Upgrade and compatibility

No breaking changes are known and no migration is required. Existing settings,
automatic restore and version-1 reference-only `.flightlens` sessions remain
compatible. AI settings live separately; keys and summaries are never saved in
sessions. Bundled firmware schemas and supported Betaflight boundaries are
unchanged. iNav and ArduPilot remain recognition-only. Existing configuration
exports are unchanged; Markdown AI summary export is a separate operation.
Inspection, comparison, audits and configuration exports remain offline, and
source backups remain read-only. Model output never changes analysis results.

This delivers configuration/comparison summaries ahead of the Phase 3 telemetry
pipeline; it does not complete Phase 3.

## Known limitations

- Live cloud-provider and installed Ollama smoke checks remain pending. Provider
  wire-format tests do not establish account or model availability.
- Tagged Windows/macOS workflows build the installers with the locked dependencies.
  Packaged credential-store, save-dialog, clipboard and license/corresponding-source
  bundle smoke checks remain pending.
- Responses are non-streaming. Token/cost reporting, telemetry summaries,
  user-editable prompts and summary persistence in sessions are deferred.
- Unknown or non-comparable settings remain explicitly uncertain. A summary is
  model-generated commentary, not a flight-performance finding or tuning advice.
- Model overrides may reject the configured request parameters. Native credential
  services may be unavailable; session-only storage must be selected explicitly.
- Installers remain unsigned and macOS notarization is absent.

The milestone notes are published after both tagged installer workflows pass.

Local validation on 2026-09-18 passed `./test.sh` (including 27 shell, 94
frontend and 37 browser tests and the real-backup corpus gate), all six
`pnpm screenshots:check` scenarios, the production build and formatting checks.
