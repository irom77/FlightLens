# FlightLens 0.4.0

Compare settings side by side alongside the angular velocity overlays.

## What changed

- Compare global settings and independently selected PID and rate profiles from two backups.
- Highlight changed values, search settings, and hide equal values.
- Distinguish declared values, certified firmware defaults, and unknown values.
- Expand a source-line link to read the original declaration.
- Missing, invalid, or unsupported values remain unknown rather than being treated as changes.

## Upgrade and compatibility

No breaking changes are known. Automatic file restore and saved preferences remain
compatible; no migration is required. Comparison selections remain temporary and
reset when leaving the view. Portable `.flightlens` sessions are not yet supported.

Bundled firmware data and Betaflight 4.2–4.5 support are unchanged. Existing snippet
validation and export behavior are unchanged. Analysis stays offline and source
backups remain read-only.

## Known limitations

- Change classification requires the same supported firmware version. Different
  versions appear side by side as not comparable until equivalence is certified.
- Feature, port, mode, and other CLI collection commands are excluded.
- Two backups only; three-backup comparison and workspace indexing remain planned.
- Angular velocity is calculated from configuration, not measured flight motion.
- Windows/macOS runtime testing of the new parameter view remains outstanding.
  Installers are unsigned. The macOS DMG is for Apple Silicon, not Intel Macs.

## What to test

1. Open two distinct backups from the same supported firmware version and choose
   **Compare backups**. Confirm known setting differences are highlighted.
2. Change PID profile A and verify B and the rate selections stay unchanged.
3. Change a rate profile and check both its settings and angular velocity curves.
4. Search for a setting, toggle **Hide equal values**, and expand a source line.
5. Compare an incomplete backup: missing PID gains must remain unknown, not zero.
6. Compare different firmware versions: known values should say **Not comparable**.
7. Close a selected backup and confirm the comparison clears until replaced.

Report OS, architecture, steps, and expected versus actual behavior without
including private backup contents.
