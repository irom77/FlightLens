# FlightLens 0.2.2 — Phase 1 inspection milestone

The Betaflight inspection MVP is complete. This patch fixes saved-session
cleanup and records the remaining Phase 2 work. The interface is largely
unchanged from 0.2.1.

## Changes

- Closing a document removes every saved path to identical imported content;
  duplicate backups stay closed after restart.
- Recognized text artifacts also stay closed when their document identity differs
  from the native source identifier.
- Phase 2 now distinguishes shipped restore and installer support from upcoming
  workspace indexing, comparison, portable sessions and native integration work.

## Upgrade and compatibility

No breaking changes are known. Existing saved sessions and settings retain their
format; no migration or user action is required. Bundled firmware data,
Betaflight 4.2–4.5 support, and documented snippet exports are unchanged.
Portable `.flightlens` sessions are not yet supported. Inspection remains offline
and source backups remain read-only.

## Known limitations

Windows/macOS runtime checks and disconnected-source behavior still need user
validation. Linux/WSL checks passed for duplicate, changed, missing and unreadable
sources, picking, X11 drag-and-drop, clipboard export and snippet saving.
Installers remain unsigned; macOS is not notarized. Unsupported firmware and
omitted settings retain the existing partial-data limitations. This milestone
is not a 1.0 stability declaration.

## Installer test checklist

Use disposable copies of backups for file changes and removal below.

1. Install and launch; confirm version 0.2.2. Existing preferences and open files
   should survive the upgrade. Check both light and dark themes.
2. Open two byte-identical copies at different paths. Expect one document. Close
   it, fully quit the app, and reopen: neither copy should return.
3. Leave a backup open and restart: it should restore. With the app stopped,
   edit the craft name in a disposable copy, then restart: expect the new name.
4. With the app stopped, move a saved disposable backup away. Restart: expect a
   warning. Restart again: that missing path should no longer be reported.
5. Open files through the picker and by dragging from Explorer or Finder. Check
   Rates, PID, Raw and Audit; changing profiles should update the relevant data.
6. Validate a Rates export. Copy it into a plain-text editor, then Save As to a
   new file: the texts should match. Cancelling Save As should report cancellation.
   Do not apply the snippet to a controller for this test.
7. Check original backup contents remain unchanged. Report OS/architecture, the
   step, expected versus actual behavior, and any error text; redact private data
   from screenshots or reports.

For removable media, also note whether a saved backup disconnected before launch
warns clearly and whether it must be opened manually after reconnecting.
