# FlightLens 0.5.0

FlightLens adds offline inspection and export support for Betaflight 2025.12
backups. Prerelease and custom-build headers retain their full version instead
of appearing as unknown. Named serial ports and numeric aliases preserve their
UART identity, and snippets use the syntax appropriate to the firmware version.
Valid `feature 3D` enable/disable commands no longer cause false syntax errors
or block OSD and serial snippets.

## Upgrade and compatibility

No breaking changes are known, and no migration or other user action is required.
Saved workspace paths and settings retain their existing format. Portable
`.flightlens` session files are not yet supported. Backups remain read-only,
and inspection works entirely offline.

Bundled schemas cover Betaflight 4.2, 4.3, 4.4, 4.5, and now 2025.12. The new
schema inputs, rate equations, and rate defaults are verified against upstream
2025.12.1–2025.12.5. Custom and prerelease builds can use the compatible schema
for explicit settings, but omitted defaults remain unknown. Export still requires
compatible destination metadata and validated explicit inputs; named serial
exports now support 2025.12.

## Known limitations

- Twelve 2025.12 settings have unresolved bounds and remain excluded from export.
  Build-dependent limits, full unsigned 32-bit values, hardware-specific schema
  entries, and arrays need further coverage.
- The local 14-backup corpus retains 16 schema diagnostics. All observed rate
  and PID profiles have complete inspection data, but some snippet groups remain
  blocked by validation or incomplete export dependencies.
- Cross-version parameter equivalence and three-backup comparison remain open.
- Packaged Windows/macOS native integration still needs manual verification.
  Installers remain unsigned; macOS notarization is not provided.

The full local test suite and screenshot checks are required before publication.
