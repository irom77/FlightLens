# FlightLens 0.9.0

Compare two or three backups with shared angular-velocity and throttle graphs,
independent rate/PID profiles, and an explicit baseline for three-way parameter
and collection comparisons. Unknown values and compatibility limits remain visible.

Browse a selected backup folder recursively with searchable, paginated metadata
indexing, cancellation, and refresh after files move or drives reconnect.

Save and open reference-only `.flightlens` sessions with workspace locations,
active backup, tab/theme, profile selections, comparison order and baseline.
Retry and hash-checked relinking recover moved backups. Save As preserves
unavailable references and selections without overwriting backups or existing files.

Phase 2 items 4–6 are implemented. Native OS file routing (item 7) and packaged
platform validation (item 8) remain outstanding.

## Upgrade and compatibility

No breaking changes are known. No migration is required. Automatic saved paths
and existing settings remain compatible. Portable sessions introduce a new
version-1 format; releases before 0.9.0 cannot open these manifests. Unsupported
manifest versions are rejected, and no backup contents are embedded.

Bundled schemas continue to cover Betaflight 4.2, 4.3, 4.4, 4.5 and 2025.12.
Certified mappings, throttle-model version restrictions, and validated exports
are unchanged. File-backed iNav/ArduPilot text backups remain recognition-only.
All inspection stays offline and source backups remain read-only.

## Known limitations

- Portable sessions exclude pasted inputs and header-only Blackbox imports.
  Save pasted backups separately and reopen the files before including them.
- Relinking requires identical contents; inspect changed files separately.
  Save As creates a new manifest; open it to establish the new retry target.
- Comparison requires distinct supported configurations. Missing profiles and
  unavailable comparisons produce explicit messages.
- Indexing skips links and is bounded to 10,000 backups, 100,000 directory
  entries and 64 levels. Text reads are limited to 16 MiB; sessions to 32
  references and 256 KiB.
- Native Windows/macOS picking, recovery, disconnected-drive and other desktop
  smoke checks remain pending. Installer builds do not replace those checks.
- Installers remain unsigned and macOS notarization is absent. Relicensing and
  installer-signing tasks have been removed; GPL-3.0-or-later remains in effect.

Release checks include the full local suite, native session tests, and both
README screenshot themes. Tagged workflows build and publish Windows and macOS
installers.
