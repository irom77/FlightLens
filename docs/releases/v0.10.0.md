# FlightLens 0.10.0

Throttle previews now support ProSpec backups on `4.5.3.KAACK_V19` and
ProSpec2 backups on `2025.12.3-alpha.KAACK_V19`. The latter uses its own
hover-dependent calculation and shows the imported hover setting with source
navigation. Official Betaflight 4.3.2 throttle previews are also supported.
Calculations were checked against C from the exact public firmware revisions,
and both current ProSpec backups were verified locally without changing them.

Phase 2 is complete within the revised items 1–6 scope. Native file routing and
packaged platform smoke validation are deferred, not completed. The roadmap,
README and TODO now state that boundary consistently.

## Upgrade and compatibility

No breaking changes are known and no migration is required. Existing settings,
automatic restore and version-1 reference-only `.flightlens` sessions remain
compatible. The session format, bundled firmware schemas and documented exports
are unchanged. Bundled schema lines remain Betaflight 4.2, 4.3, 4.4, 4.5 and
2025.12; throttle support expands only to the exact releases listed above.
Other vendor suffixes are not automatically certified. iNav and ArduPilot text
backups remain recognition-only. Inspection stays offline and backups read-only.

## Known limitations

- Throttle previews require explicit valid settings in the selected rate profile.
  Older diff backups with omitted defaults can still have unavailable graphs.
- Official 2025.12 throttle previews remain unavailable pending separate release
  verification. Legacy MID=100 remains unavailable; the supported hover model
  follows its distinct firmware behavior at that midpoint.
- Charts represent configured throttle commands, excluding runtime mixer effects.
- Portable sessions exclude pasted inputs and Blackbox imports; relinking requires
  identical backup contents.
- Native file routing and packaged Windows/macOS smoke checks remain deferred.
  Installers are unsigned and macOS notarization is absent.

Validation includes compiled firmware C differential fixtures, the full local
`./test.sh` suite, and light/dark README screenshot checks. Tagged workflows build
and publish Windows and macOS installers.
