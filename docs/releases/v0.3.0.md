# FlightLens 0.3.0

Compare calculated angular velocity between two backups, the first comparison
feature in Phase 2.

## What changed

- Open two different backups and choose **Compare backups** in the sidebar.
- Select backups A and B and a rate profile independently for each.
- Compare roll, pitch, and yaw curves on shared scales per axis, with angular
  velocity in °/s versus stick input. Hover to see values at the same stick position.
- Source/profile labels, solid/dashed lines, and explicit unknown-data and
  firmware-default messages help interpret the results.
- Closing a selected document clears the comparison until a replacement is chosen.

## Upgrade and compatibility

No breaking changes are known. Existing automatic file restore and preferences
remain compatible; no migration is required. Comparison selections are temporary
and are reset when leaving the comparison view. Portable `.flightlens` sessions
are not yet supported.

Bundled firmware data and Betaflight 4.2–4.5 support are unchanged. Existing snippet
validation and export behavior are unchanged. Analysis stays offline, and original
backups remain read-only.

## Known limitations

- This compares configuration-derived angular velocity, not measured flight motion.
  Blackbox telemetry is planned for Phase 3.
- Two backups only. Semantic parameter differences, three-backup comparison, and
  workspace indexing are still planned.
- Identical backup contents share one document; use two distinct configurations.
- Missing or unsupported rate inputs cannot produce a curve.
- Windows/macOS runtime testing of comparison remains to be completed. Installers
  are unsigned; the macOS DMG targets Apple Silicon, not Intel Macs.

## What to test

1. Install and open two disposable backup copies with different rates or Expo.
2. Choose **Compare backups** and confirm all available axis curves appear with
   identifiable A/B labels and solid/dashed lines.
3. Change one rate profile; confirm the other profile selection remains unchanged.
4. Hover each plot and compare the °/s values. Try an incomplete backup and confirm
   missing inputs are reported rather than plotted as zero.
5. Close a selected backup; confirm its curves disappear. Choose a replacement.
6. Return to the inspector and check normal Rates inspection and export still work.

Report the OS, architecture, steps, and expected versus actual behavior. Keep
private backup contents out of reports and screenshots.
